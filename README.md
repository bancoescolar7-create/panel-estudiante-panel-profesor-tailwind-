# Moneda Educativa — Prototipo HTML y Tailwind CSS

Este proyecto contiene dos prototipos visuales basados en los wireframes del punto 11:

- `estudiante.html`: panel del estudiante.
- `profesor.html`: panel del profesor.

## Cómo probarlo
1. Abre `Index.html` en un navegador.
2. Tailwind CSS se carga mediante CDN, por lo que necesitas conexión a internet para ver los estilos.

## Importante
Es un prototipo inicial para la actividad. Usa datos de ejemplo y no tiene backend ni base de datos conectados. El formulario del profesor permite probar visualmente la validación de cantidades y evita un saldo negativo, pero los datos no se guardan al cerrar o recargar la página.

## Tecnologías
- HTML
- Tailwind CSS (CDN)
- JavaScript básico para la demostración del panel del profesor

## Subirlo a GitHub
1. Crea una cuenta en https://github.com/ si aún no tienes una.
2. Pulsa **New repository** y crea uno llamado `moneda-educativa`.
3. Sube los archivos de esta carpeta al repositorio.
4. Invita a los compañeros desde **Settings → Collaborators** (el nombre de la opción puede variar).
5. Copia la URL del repositorio y pégala en la entrega del punto 14.

No se incluye una URL de repositorio porque debe ser creada desde la cuenta de un integrante del equipo.
